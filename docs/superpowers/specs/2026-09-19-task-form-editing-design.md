# طراحی افزودن و ویرایش کار

## هدف

صفحهٔ «کارها» فقط از فرم کامل برای افزودن استفاده می‌کند، کارهای موجود قابل ویرایش می‌شوند، و کار می‌تواند انجام‌شدنی، تعدادی یا زمانی باشد. افزودن سریع فقط در کارت کارهای صفحهٔ «امروز» باقی می‌ماند و کارهای سریع پشت‌سرهم رنگ‌های متفاوت می‌گیرند.

## محدودیت‌ها

- هیچ migration، DDL، پاک‌سازی یا بازنویسی داده اجرا نمی‌شود.
- رکوردهای قدیمی کار بدون تغییر معتبر و قابل نمایش می‌مانند.
- بخش عادت‌ها و فایل‌های آن تغییر نمی‌کنند.
- کارهای زمانی فقط برای روز خودشان هستند و کار زمانیِ بازِ امروز از مسیر فعلی تایمر قابل اتصال است.
- رفتار مرتب‌سازی تأخیری، swipe و بازخورد تکمیل فعلی حفظ می‌شود.

## تجربهٔ کاربری

### صفحهٔ کارها

- دکمهٔ «پیشرفته» و ورودی متنی افزودن سریع حذف می‌شوند.
- یک کنترل واضح «افزودن کار» همان فرم کامل را باز می‌کند.
- فرم تاریخ، عنوان، نوع سنجش، هدف، رنگ، آیکون، یادداشت و یادآوری را می‌گیرد.
- نوع سنجش شامل «انجام شد / نشد» و «مقداری» است. در حالت مقداری، کاربر میان «تعدادی» و «زمانی» انتخاب می‌کند.
- حالت تعدادی هدف عددی دارد. حالت زمانی از DurationPicker موجود برای ساعت، دقیقه و ثانیه استفاده می‌کند.

### ویرایش

- هر TaskRow یک دکمهٔ ویرایش قابل دسترس دارد.
- ویرایش از صفحهٔ کارها و کارت کارهای صفحهٔ امروز در دسترس است.
- فرم ویرایش با مقادیر فعلی باز می‌شود و تاریخ را هم می‌تواند تغییر دهد.
- تغییر هدف یا نوع سنجش، مقدار فعلی را در محدودهٔ معتبر نگه می‌دارد و وضعیت done را دوباره محاسبه می‌کند.
- تاریخ یادآوری هنگام انتقال کار به روز دیگر با ساعت انتخاب‌شده هماهنگ می‌شود.

### رنگ کار سریع

- افزودن سریع در صفحهٔ امروز از CATEGORY_COLOR_CHOICES استفاده می‌کند.
- رنگ بر اساس آخرین کارهای همان روز چرخش می‌کند تا کارهای متوالی هم‌رنگ نباشند.
- این مقدار در فیلد اختیاری color ذخیره می‌شود؛ رکوردهای قدیمی بدون color همچنان با رنگ پیش‌فرض نمایش داده می‌شوند.

## داده و سازگاری

- ساختار جدول/پایگاه داده عوض نمی‌شود؛ کارها همان رکوردهای JSON موجود هستند.
- مدل Task و قرارداد sync تغییر نمی‌کند و همان فیلدهای فعلی type، target و unitKind برای حالت‌های سنجش استفاده می‌شوند.

## آزمون

- تبدیل draft به Task برای حالت‌های binary، count و time.
- تبدیل Task قدیمی به draft بدون نیاز به مهاجرت.
- رنگ‌های متوالی افزودن سریع.
- باز شدن ویرایش از TaskRow و حفظ رفتار تکمیل.
- فرم کامل صفحهٔ کارها و باقی‌ماندن افزودن سریع در TodayTodosCard.
- آزمون سازگاری مدل فعلی بدون نیاز به فیلد یا migration جدید.
