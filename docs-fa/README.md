## 📍 الان کجاییم؟

جدولِ «چی مونده تا لانچ» در بخش **وضعیت فعلی لانچ** فایل
[DEPLOY-SUPABASE-EDGE.md](DEPLOY-SUPABASE-EDGE.md) است. خلاصه‌اش (۱۳ مرداد ۱۴۰۵):
همه‌ی کد و سایت و استقرار تمام است؛ فقط دو حساب بیرونی مانده — **کاوه‌نگار**
(بدون آن کاربر جدید نمی‌تواند ثبت‌نام کند) و **مرچنت واقعی زرین‌پال** (بدون آن پول
به حساب نمی‌رسد) — به‌علاوه یک بار اجرای `supabase/setup.sql` در پنل Supabase.
