# چک‌لیست دستی یادآور نیتیو

این فایل برای build release روی گوشی واقعی است. تست‌های TypeScript و بررسی manifest جای تست سخت‌افزاری را نمی‌گیرند.

## آماده‌سازی

- [ ] نسخه تازه نصب شود: هیچ permission dialog خودکار در boot نمایش داده نشود و کلید اعلان خاموش باشد.
- [ ] با روشن‌کردن صریح کلید Settings، permission نمایش و در Android 12+ صفحه exact alarm فقط همان‌جا باز شود.
- [ ] حالت denied نشان دهد کلید مؤثر خاموش است؛ بعد از فعال‌کردن permission در تنظیمات OS و foreground، reminderها دوباره ساخته شوند.

## زمان‌ها و برنامه‌ها

- [ ] عادت روزانه در `07:00` و `08:00`، task در `12:30` و ژورنال در `23:50` در همان دقیقه تحویل شوند.
- [ ] عادت دوشنبه/چهارشنبه در روزهای دیگر هیچ اعلانی ندهد.
- [ ] زوج/فرد در تقویم شمسی و میلادی، مخصوصاً مرز پایان ماه، با صفحه امروز یکی باشد.
- [ ] تغییر ساعت reminder، completion و delete آلارم قدیمی را حذف کند و duplicate نسازد.
- [ ] چند reminder نزدیک با ID و متن درست نمایش داده شوند.

## شرایط سیستم

- [ ] اینترنت خاموش، app در background، app killed و battery saver هرکدام جداگانه آزمایش شوند.
- [ ] بعد از reboot و بعد از نصب update روی همان نسخه، pending reminder باقی بماند/restore شود.
- [ ] timezone عوض شود، اپ foreground شود و زمان محلی جدید بدون duplicate اعمال شود.

## وضعیت اجرای این جلسه

- [x] planner، permission boundary، ظرفیت و idempotency با تست خودکار بررسی شد.
- [x] وجود APIهای Capacitor v7، exact-alarm manifest و boot receiver در کد نصب‌شده بررسی شد.
- [ ] تست گوشی فیزیکی انجام نشده است؛ drift سخت‌افزاری هنوز تأییدشده نیست.
